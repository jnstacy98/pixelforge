# PixelForge

A Photoshop-inspired desktop image editor built with Electron + TypeScript. Opens and saves **layered PSD files** and edits all common image formats with brushes, layers, blend modes, selections and filters.

## Features (v0.14)

| Area | What works |
|---|---|
| **Import layers** | **File ▸ Import Layers from File…** (or **Shift+drop** files onto the window) merges another document into the open one: all its layers — groups, masks, layer styles, text and vector shapes (still editable), adjustment layers, smart objects with their embedded files — are placed above the active layer, **centred** or at the top-left, optionally inside a new group named after the file, or as **one flattened layer**. Identical embedded smart-object files are shared instead of duplicated; clashing ids get a fresh one. One undo step removes everything again. |
| **Files** | Open/save **PSD** (layers, names, opacity, visibility, blend modes preserved; groups are flattened into layers). Open PNG, JPEG, WebP, GIF, BMP, AVIF, ICO, SVG and **TIFF** (LZW / PackBits / Deflate; 8- and 16-bit RGB, gray, palette, CMYK, with alpha; multi-page files open as one layer per page). Export PNG, JPEG, WebP, BMP, **TIFF** (uncompressed 8-bit RGBA) and PSD. Drag & drop, multiple document tabs. |
| **Layers** | Add, duplicate, delete, reorder (drag or buttons), merge down, flatten, rename (double-click), visibility, opacity, 16 blend modes. |
| **Groups** | Nested layer groups: **Ctrl+click / Shift+click** layers in the panel then **Ctrl+G** (or the folder button) to group; **Ctrl+Shift+G** ungroups. Drag layers into / out of / between groups (top/bottom edge = before/after, middle of a group = inside). Collapse with the arrow. Each group has its own visibility, opacity, **Pass Through** (default) or ordinary blend mode, and an optional **group mask** you can paint. Isolated groups composite as a unit, so adjustment layers inside only affect the group's contents. Duplicate, delete, move (Move tool carries everything inside), Merge Group, Flatten — all undoable. **PSD groups import and export as real groups** (nesting, opacity, blend, mask, hidden, open/closed). |
| **Layer masks** | Add Reveal All / Hide All / From Selection; paint on the mask with any tool (white reveals, black hides; brush, eraser, bucket, gradient, fills, filters and Invert all work on masks). Click the mask thumbnail to edit it, Shift+click to disable. Apply or delete a mask from the Layer menu. Masks move with their layer, survive merge/duplicate/flip/resize, and **round-trip through PSD**. |
| **Text** | Text tool (`T`): click to type, click existing text to re-edit. Font, size, bold, italic, alignment, color (foreground). Text stays an editable layer — move it, restyle it, mask it, blend it. Painting on it or applying filters rasterizes it (undoable). |
| **Clone Stamp** | `S`: Alt+click to set the source, then paint to copy pixels from it. Soft/hard brush tip, size, opacity, flow, spacing, pen pressure. **Aligned** (offset carries across strokes) or restart from the source each stroke. Sample **current layer**, **current & below**, or **all layers** (clone onto a new empty layer without touching the original). A live overlay shows where you're sampling from. Respects selections, works on layer masks, one undo step per stroke. |
| **Healing** | **Healing Brush** (`J`): like the Clone Stamp (Alt+click source, aligned, sample layer / below / all), but when you release, the patch keeps the source's *texture* and takes its colour and lighting from the surroundings — blemishes vanish without a ghost or seam. **Spot Healing** (`K`): just paint over a blemish; PixelForge searches nearby areas for the one whose surroundings match best and heals from it. Seamless membrane blending (push-pull pyramid + relaxation), one undo step per stroke, works with selections. |
| **Brush & eraser** | Size, hardness, opacity, flow, spacing; pen-pressure sensitivity and **pen tilt** (a leaning pen flattens the dab into an ellipse along the lean; toggle "Pen tilt"); stroke-level opacity like Photoshop. `[` / `]` resize. **Custom brush tips**: six built-in tips (square, diamond, star, chalk, splatter, bristles) plus **Edit ▸ Define Brush Tip from Selection** (black = paint, or the layer's transparency as the shape); tip angle and *Follow stroke*. User tips are remembered between sessions. Clone / eraser use the tip too. |
| **Tools** | Move, rectangular marquee, brush, eraser, paint bucket (tolerance/contiguous), gradient, eyedropper, hand. |
| **Selection** | Rectangle & ellipse marquee, freehand **and polygonal lasso** (press `L` again to switch; click corners, click the first point / double-click / Enter to close, Backspace removes a point, Esc cancels), **Quick Selection** (`Q`: paint over an object and the selection grows along colour edges), magic wand (tolerance, contiguous, sample all layers). **Shift** adds, **Alt** subtracts, **Shift+Alt** intersects. Select ▸ All / Deselect / Inverse (`Ctrl+Shift+I`) / Feather. Irregular selections limit brush, eraser, bucket, gradient, fills, filters and move, and can become a layer mask. Selection changes are undoable. |
| **Image** | Image size, canvas size, rotate 90°, flip H/V. |
| **Patch tool** | `P`: draw a freehand selection around a blemish / object (or use any existing selection), then drag it. **Source** mode repairs the selected area with the texture of the area you drag the outline onto; **Content-Aware** mode builds brand-new content for the area (sampling mainly from where you drop the outline); **Destination** mode copies the selected content to where you drop it (the selection travels with it). You see a live preview while dragging; on release the patch is blended so its tone and lighting match its surroundings (same boundary-matching maths as the Healing Brush), or switch off *Match tone & texture* for a plain copy. Shift/Alt add/subtract when drawing; sample from the current layer, current & below, or all layers; one undo step. |
| **Content-Aware Move** | `O`: draw around an object and drag it. **Move** mode drops it at the new place (tone and lighting matched to its surroundings) and fills the hole it left with Content-Aware Fill, all as one undo step; **Extend** mode leaves the original and adds a blended copy (handy for repeating or lengthening things). A progress overlay with Cancel shows while the hole is filled. |
| **Blend If** | Layer Style button ▸ **Blend If…**: Gray / Red / Green / Blue sliders for **This Layer** and **Underlying Layer**, each with split black and white points for a soft ramp. Hides parts of a layer by its own tones or by what is beneath it, live, undoable, and **read from / written to PSD** blending ranges. |
| **Smart objects** | Photoshop smart objects are kept as smart objects: their embedded source (JPEG / PNG / PSD…) and placed transform survive opening and re-saving a PSD (checked on a real Photoshop file with two). A badge marks them in the Layers panel. **Layer ▸ Smart Object: Edit Contents** (or double-click the thumbnail) opens the source in its own tab; **Update Smart Object** sends the result back and re-renders the layer through its transform. **Transform…** scales / rotates it from the source so nothing degrades; **Convert to Smart Object** embeds any pixel layer; **Rasterize Layer** drops the link. Undoable. |
| **Smart filters** | **Layer ▸ Smart Filters…** (on an ordinary layer it converts to a smart object first): a non-destructive filter stack on a smart object — **Gaussian Blur, Box Blur, Motion Blur, Unsharp Mask, Add Noise, Mosaic, Invert, Brightness/Contrast**. Turn each on / off, edit its settings, reorder or delete it; every change re-renders the layer from its original embedded source, so nothing is baked in, and it keeps working through Free Transform, Transform… and Update Smart Object. **Filter masks**: Layer ▸ Add Filter Mask (or the button in the Smart Filters panel) puts a white mask over the whole stack — paint black on it with any brush, gradient or selection fill to keep parts of the object unfiltered; the stroke previews live, and the mask has its own thumbnail in the Layers panel. Each change is one undo step. Filters are written into saved PSDs as Photoshop smart-filter records (and read back from them); Photoshop smart filters PixelForge can't run are kept and saved back untouched. |
| **Free Transform** | `Ctrl+T` (Edit ▸ Free Transform): drag the corner / edge handles to scale (Shift = keep proportions, Alt = from the centre, dragging past the opposite side flips), drag inside to move, drag outside to rotate (Shift snaps to 15°), or type W % / H % / Angle in the options bar. The **Mode** menu adds **Skew** (drag edges), **Distort** (drag corners or edges), **Perspective** (drag a corner and its neighbour mirrors it) and **Warp** (a 4×4 Bézier control lattice: drag any of the 16 points to bend the layer); these are rendered through a fine, anti-aliased mesh when you apply. `Enter` or choosing another tool applies, `Esc` cancels; one undo step. With a selection only the selected pixels transform. On a **smart object** it edits the placed transform and re-renders from the embedded source, so nothing degrades. |
| **Vector shapes** | `U`: draw **rectangles (with corner radius), ellipses, polygons, stars, lines** and **Bézier pen paths** (click for a corner, click-and-drag to pull out smooth curve handles, click the first point to close, Enter / double-click to leave it open). Select a path layer with the Shape tool to edit it: drag anchors and handles, **Alt+click** an anchor to switch smooth ⇄ corner, **Ctrl+click** a segment to add an anchor, **Delete** removes the selected anchor. Each is a *shape layer*: fill and stroke colours, stroke width, radius, sides and star depth stay editable from the options bar (live, undoable), and moving (Move tool) or scaling / rotating (`Ctrl+T`) changes the shape's matrix and re-renders it, so edges stay razor-sharp at any size. Shift = square / circle / 45° line, Alt = from the centre. Painting on a shape layer rasterizes it (undo brings the vector data back); Layer ▸ Rasterize Shape does it explicitly. **Combine Shapes** (Layer menu, with two or more shape layers selected via Ctrl/Shift+click): **Unite, Subtract** (lowest layer minus the others), **Intersect** or **Exclude Overlap** — the result is one compound shape layer (holes included) that keeps the first shape's fill and stroke and stays resolution-independent; one undo step brings the originals back. Layer styles, masks, blend modes and clipping work on shape layers like on any other. |
| **Text on a path** | With the Text tool, click a shape's outline (rectangle, ellipse, polygon, pen path, combined shape…) and type: the text follows the outline, each glyph rotating with the curve (kerning-aware spacing). The options bar adds **Path offset** (where the text starts along the path; with *Center* / *Right* alignment it is the centre / end) and **Other side** (runs the other way, on the other side of the outline). Click the text again to edit it; moving the layer moves its path; **Alt+click** makes ordinary text even on an outline. Text stays editable and undoable like any text layer. |
| **Content-Aware Fill** | Select something (marquee, lasso, wand…) and choose **Edit ▸ Content-Aware Fill… (Shift+F5)** to remove it: the hole is re-synthesised from patches of the rest of the layer (or all visible layers), so textures, grass, sky, water, walls and simple structures carry on through it. PatchMatch-based multi-resolution inpainting with a progress overlay and **Cancel**; options for selection expansion (avoids halos), sample source and quality. Never copies from the hole itself, leaves pixels outside the selection untouched, one undo step. |
| **Layer styles** | **Contours** (13 Photoshop presets, plus a free-form **contour editor** — click to add points, drag, double-click to remove, optional straight-segment *Corner* mode, live preview on the layer — with a curve preview) on Drop / Inner Shadow, Outer / Inner Glow, Satin and Bevel (shape contour and gloss contour), imported from and written to PSDs; **Pattern Overlay** (built-in tiles, patterns stored in PSDs, or **New pattern from selection / layer**; scale, angle, blend, opacity; tiles travel inside saved PSDs), **Bevel & Emboss** (Inner / Outer Bevel, Emboss, Pillow Emboss, Stroke Emboss; Smooth / Chisel Hard / Chisel Soft; depth, up/down, size, soften, light angle & altitude, highlight and shadow colour / blend / opacity), plus **Drop Shadow, Inner Shadow, Outer Glow, Inner Glow, Satin, Color Overlay, Gradient Overlay** (linear / radial / angle / reflected, multi-stop with per-stop opacity, scale) and **Stroke** (inside / center / outside) on pixel and text layers, via the **fx** button, double-click on the fx badge, or Layer ▸ Layer Style…, with a live-preview dialog. Stacked in Photoshop's order; shadows and outer glows blend with the layers *beneath* (a Screen glow vanishes over white, a Multiply shadow darkens the colours under it); shaped by the layer's mask; respect Opacity (scales effects too) and **Fill** opacity (pixels only — set Fill to 0 for "ghost" text with just a glow/stroke). Copy / Paste / Clear Layer Style, undoable, baked on Merge Down. **PSD layer styles import and export** (including the document's Global Light angle). Rendering is cached per layer, works only in the layer's bounding box + effect reach, and uses an exact distance transform for crisp strokes and spreads. |
| **Clipping masks** | **Ctrl+Alt+G** (or the ↳ button / Layer menu) clips the selected layer(s) to the shape of the layer below — classic "photo inside text", shading and texture on a shape, or an adjustment that only touches one layer. Works for pixel layers, text, groups and adjustment layers; the base's opacity and blend mode apply to the whole stack; hiding the base hides what's clipped to it; masks on the base cut the clipped layers too. Painting on a clipped layer is non-destructive (the paint stays on the layer). Merge Down / Merge Clipping Mask bake it. **PSD clipping flags import and export.** |
| **Adjustments** | **Levels** (input black/white, gamma, output range, per-channel, histogram, Auto) and **Curves** (smooth overshoot-free curve, add/drag/remove points, per-channel, presets) with live preview. Also Auto Levels, brightness/contrast, hue/saturation, invert, desaturate, sepia. Adjustments respect selections and work on layer masks. |
| **Adjustment layers** | Non-destructive **Levels, Curves, Brightness/Contrast, Hue/Saturation, Invert, Posterize, Threshold, Exposure, Vibrance, Black & White (with tint), Photo Filter, Color Balance, Selective Color (relative/absolute), Color Lookup (load a `.cube` 3D LUT), Channel Mixer (incl. monochrome) and Gradient Map** layers (Layers panel ◐ button or Layer menu). They affect everything below them, come with a layer mask (paint to limit the effect), an opacity and a **blend mode** (e.g. Luminosity or Color to limit a Curves layer to tone or colour), and stay editable — double-click the icon to reopen the dialog. Merge Down bakes one into the layer below; Flatten renders them. **Photoshop's own versions of all of these open as editable adjustment layers** (checked against a real Photoshop file: the 17-layer adjustment stack now matches Photoshop's own preview to well under 1/255 on average) and are written back to PSD. |
| **Filters** | Gaussian blur. |
| **Editing** | Undo/redo history (100 steps), zoom/pan (wheel, Space-drag), fit/100%. |

### Known limitations
- Layers are document-sized (pixels moved off-canvas are cropped).
- PSD: layer effects are only partly preserved (see below). Non-`.cube` Color Lookup tables and noise-type Gradient Maps open as hidden placeholders with a warning. Brightness/Contrast and Hue/Saturation use PixelForge's own formulas, so they look *similar* but not identical to Photoshop's. Hue/Saturation's per-colour ranges and Lightness are ignored.
- Smart filters: the filter mask is not saved in PSDs (the saved pixels carry the masked result, but reopening the file loses the mask), it doesn't move with the object when it is transformed, and filters have no per-filter blend / opacity; blurs treat the canvas edge as a replicated border; settings are not live-previewed (each is applied, and undoable, immediately); the Photoshop smart-filter records PixelForge writes were round-tripped through the PSD library but not checked in Photoshop itself, and blur radii/noise amounts are close to, not identical with, Photoshop's.
- Text on a path: the path is copied into the text layer when you start typing (later edits to the original shape don't reflow the text), one line only (newlines become spaces), glyphs beyond the end of an open path are dropped, and there is no per-glyph kerning pair table beyond the browser's own; Free Transform rasterizes it like any text.
- Combine Shapes: curves are flattened to fine straight segments (about 1.5 px each) in the combined result, so a combined shape that is later scaled up a lot shows facets; compound shapes can't be edited anchor-by-anchor, and open paths / lines can't be combined.
- Vector shapes: PSD export writes shape layers as ordinary pixel layers (Photoshop shows no vector path), strokes are centred on the edge (no inside / outside), there is no gradient / pattern fill, and the pen tool has no separate corner-handle modes (Alt-drag while drawing makes a one-sided handle; Alt-dragging a handle later breaks the link). Shape data lives in PixelForge documents' undo history, not in saved files.
- Free Transform: no pivot-point dragging, no preset warp shapes (arc, flag…), and Skew / Distort / Perspective / Warp aren't available on smart objects (rasterize first). Warp control points sit on a Bézier lattice, so the surface follows them loosely rather than passing through them; pixels are resampled once on apply, so repeated transforms of ordinary layers do degrade (use a smart object to avoid that). While the transform is open the preview is drawn above all layers and ignores the layer's effects and blend mode. Transforming a text layer rasterizes it.
- Smart objects: only the affine part of the placed transform is used (perspective / warp / smart filters are ignored when re-rendering; the stored pixels still show Photoshop's own render until you edit or transform), linked (external) files aren't followed, and painting on a smart layer turns it into an ordinary layer when saved. Edit Contents works for embedded files PixelForge can open (PSD, PNG, JPEG, TIFF…).
- Pen tilt: only tilt (not rotation / barrel pressure) is used, only for brush & eraser, and it was verified with synthetic pen events rather than real hardware.
- Brush tips: tips are alpha masks only (no per-dab colour from the tip image, no scatter / jitter / texture, no `.abr` import), at most 256 px, stored in the browser's local storage rather than in documents.
- Quick Selection: a colour-similarity flood within three brush radii of each stamp (no edge-detection or auto-enhance), so low-contrast edges may leak — lower the tolerance or the brush size.
- Blend If: only pixel/text layers (not groups or adjustment layers); sliders are judged against the composite beneath the layer at its own stack position; merging a layer down does not bake its Blend If; Photoshop's Alt-drag half-slider UI is replaced by four separate sliders.
- Content-Aware Move: no rotate/scale of the moved object, no "Structure"/"Color" sliders, and Extend is a blended copy rather than Photoshop's structure-adaptive stretch. The hole is filled at "Fast" quality and the move only fills from the sampled layer(s) you choose.
- Patch tool: Content-Aware mode fills at Fast quality and only uses the dropped area as a sampling hint (the fill may also draw on the surrounding crop); no "Transparent"/diffusion options; the preview while dragging is an unblended copy (the blend happens on release, as in the Healing Brush). Dragging inside the current selection moves the patch; anything outside it starts a new selection.
- Content-Aware Fill is classic patch-based synthesis, not Photoshop's exact algorithm: it works best on textures and gradients. On large holes that cross *repeating structure* (e.g. the lower half of a picket fence) it may fill with plain texture instead of continuing the structure, and can leave small fragments — undo and try a smaller selection, a different Sample setting, or fill in pieces. There is no rotation/scale/mirror adaptation. It runs on the main thread (a few seconds for a ~300×200 hole at High quality; larger holes take longer) behind a progress overlay with Cancel.
- Layer styles: Pattern Overlay tiles are anchored at the document origin (no "link with layer" / "snap to origin" options; the PSD "phase" offset is honoured), and patterns referenced by a PSD but not stored in it are skipped with a warning. Not supported: noise gradients, bevel texture, per-point corner/smooth flags in contours (Corner applies to the whole curve and isn't stored in PSDs, so a re-opened file reads its custom curves as smooth; the stock curves are approximations of Photoshop's, and contours are applied to the blurred falloff rather than Photoshop's exact pipeline), and layer styles on *groups* are not supported (reported on PSD import, then skipped); Diamond gradients are drawn as radial. Glows draw from the edge only. Shadow / glow edge profiles were calibrated against real Photoshop output (error roughly halved), but are still an approximation. Bevel lighting is a simplified model (slope along the light direction with smooth saturation, so Depth always strengthens it) rather than Photoshop's exact shading; Stroke Emboss needs the Stroke effect enabled. PSD shadow/glow *spread* is written as a plain number (the PSD writer can't store percent units), so Photoshop may read non-zero spreads differently.
- Photoshop's *Fill opacity* on Linear Light / Vivid Light-type blend modes behaves differently from Opacity; PixelForge treats Fill like Opacity there.
- Clipping masks: always "Blend Clipped Layers as Group" (Photoshop's default); the per-layer option to turn that off isn't supported. An adjustment layer can be clipped but can't be a clipping base. A clipped layer binds to whatever unclipped layer is below it in the same group, so moving layers around re-binds them (same as Photoshop).
- Groups: a Pass Through group that has a layer-opacity below 100% or a mask is composited as an isolated group (so adjustments inside it stop reaching layers outside it). Ungrouping discards the group's own opacity/mask/blend. You can't merge a layer down into a group (use Merge Group). Clipping masks and vector masks are not supported.
- Healing is applied when you release the mouse (you see a plain clone while dragging, like Photoshop). Spot Healing matches *colour* of the surroundings only — it can pick a poor source over strongly textured or patterned areas, in which case undo and use the Healing Brush with a hand-picked source.
- Import Layers: no scaling (a bigger file overhangs the canvas and is cropped by it, a smaller one sits on it), PSD text and shapes arrive as ordinary pixel layers because PSDs written by PixelForge store them that way (documents built in the same session keep them editable), and layer names are not de-duplicated.
- Large images: slider drags in adjustment / filter dialogs and moving whole layers still repaint the entire image on every change (a few hundred ms at 12 MP in the software renderer); only brush-type edits repaint locally.
- Adjustment layers: the blend mode combines the adjusted pixels with the ones below (so Color / Luminosity / Multiply etc. work), but there is no Fill opacity or Blend If on them. Each one holds a full-size blank pixel canvas, and each LUT-based adjustment costs a full-image pass per redraw (about 140 ms per layer at 12 megapixels in a software-rendered browser), so many adjustment layers on very large images will feel slower while painting. Text layers are saved as pixels, so they re-open as normal (rasterized) layers in PixelForge and Photoshop. Vector masks and mask feather/density are ignored.
- TIFF: 16-bit files are reduced to 8 bits, CMYK is converted naively (no ICC profiles), JPEG-compressed TIFFs, BigTIFF and floating-point TIFFs were not tested and may not open, and export is flattened and uncompressed. No RAW support.

## Testing
- `npm test` — 80 unit tests (pure maths: tone curves, healing, inpainting, layer styles, blend modes, PSD conversion) and ~280 end-to-end checks in headless Chromium (painting, layers, groups, masks, styles, tools, PSD round-trips).
- `npm run test:psd` — **fidelity against real Photoshop files**: downloads 16 genuine PSDs (from the MIT-licensed `ag-psd` repo; not stored here), imports each with PixelForge, renders it, and compares with the flattened preview Photoshop saved inside the file. Each file has an error budget in `tests/psd-budgets.json`, so a change that makes Photoshop fidelity worse fails. Run it on your own PSDs with `node tests/real-psd.mjs <folder> --images <outdir>` (writes side-by-side PNGs: yours | Photoshop's).

## Installing on Windows

Download **PixelForge-Setup-x.y.z.exe** from the [Releases page](https://github.com/jnstacy98/pixelforge/releases) and run it. The wizard walks through the licence, install location (per-user by default, no admin rights needed; choose "all users" if you want), and Start Menu / Desktop shortcuts, and can launch PixelForge when it finishes. PixelForge is then registered for PSD, PNG, JPEG and WebP files. Uninstall from Windows Settings ▸ Apps. A **PixelForge-Portable-x.y.z.exe** that needs no installation is also published (it can't self-update).

The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info ▸ Run anyway**.

**Help menu:** User Guide (`F1`), Keyboard Shortcuts, Documentation Online, **Check for Updates…**, Release Notes, Report a Problem, About. Installed copies also check quietly a few seconds after start-up; an update is only downloaded when you say so, and installs when you restart (or next close the app).

### Publishing an update (maintainers)
1. Bump `version` in `package.json` and commit.
2. `git tag v0.2.0 && git push origin v0.2.0` — the *Release* workflow (`.github/workflows/release.yml`) creates a draft release, builds on Windows, uploads the installer, portable exe, blockmap and `latest.yml` into it, checks they are all there, and only then publishes it. If a file is missing the release stays a draft and the run fails. (Don't create the release on GitHub by hand first. Publishing locally with `GH_TOKEN=… npx electron-builder --win --publish always` leaves a draft you publish yourself.)
3. Installed copies pick it up from **Help ▸ Check for Updates…**. The release must be published (not a draft), its tag must match the `package.json` version, and there must be only one release per tag.

## Development

```bash
npm install

npm run build       # typecheck + production build

npm test            # unit tests (tone maths) + end-to-end tests (headless Chromium via Playwright; run `npm run build` first)

```

## Performance on large images

`npm run perf` (or `node tests/perf.mjs 24`) builds a synthetic multi-layer document of the given size and times the things you do all day. Measured in headless Chromium with *software* canvas rendering (so a desktop GPU will do better), 12 megapixels, 5 layers:

| Operation | Before | After |
| --- | --- | --- |
| Brush stroke, repaint per mouse move | 83 ms | **17 ms** (frame-rate bound) |
| …with two adjustment layers above the painted layer | ≈ 550 ms (a whole-image pass per adjustment, per move) | **16 ms** |
| Start of a stroke | 64 ms | 23 ms |
| Three adjustment layers (Levels, Curves, Brightness) full repaint | 559 ms | ≈ 160 ms |
| Merge Down | 1159 ms | 107 ms |
| PSD save (13 layers, 5 masks) | 5.2 s | ≈ 3 s |
| PSD open (same file) | 6.6 s | ≈ 4 s |

What changed: strokes repaint only the rectangle they touched (every working buffer is clipped to it, so the cost follows the brush, not the image — checked pixel-for-pixel against a full repaint for masks, groups, blend modes, adjustment layers and layer styles); undo data for a stroke is read from just the touched area instead of copying the whole layer at the start; runs of plain Levels / Curves / Invert layers are merged into one pass; uniform layer masks (the white mask of every adjustment layer) are stored in PSDs as a single colour instead of megapixels of pixels; Merge Down no longer copies layers that have nothing to bake; fresh white masks are known to be "reveal all" without scanning them; and the large working buffers are released after a few idle seconds. At 24 MP a stroke still repaints in about 22 ms.
